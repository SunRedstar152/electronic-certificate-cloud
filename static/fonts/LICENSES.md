# Bundled Thai font licenses

The certificate renderer bundles these fonts so Thai text is rendered consistently in PNG, JPEG and PDF output.

## Sarabun

- Files: `Sarabun-Regular.ttf`, `Sarabun-Bold.ttf`
- Source: [Google Fonts – Sarabun](https://github.com/google/fonts/tree/main/ofl/sarabun)
- License: SIL Open Font License 1.1; see `OFL-Sarabun.txt`.

## Noto Sans Thai

- Files: `NotoSansThai-Regular.ttf`, `NotoSansThai-Bold.ttf`
- Source: [Noto Fonts – Noto Sans Thai](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSansThai)
- License: SIL Open Font License 1.1; see `OFL-NotoSansThai.txt`.

## TH Niramit AS

- Files: `THNiramitAS-Regular.ttf`, `THNiramitAS-Bold.ttf`
- Source: [โครงการฟอนต์แห่งชาติ โดยกรมทรัพย์สินทางปัญญาและ SIPA](http://sql.ldd.go.th/intraaccount/Font/Font.html)
- License: DIP & SIPA Font License Agreement; see `LICENSE-THNiramitAS.txt`.

Keep the corresponding license files with redistributed copies of these fonts.
